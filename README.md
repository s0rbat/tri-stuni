# Одностраничный сайт «Курсы по гитаре»

## Файлы

- `index.html` — структура страницы и тексты
- `styles.css` — оформление и адаптивная версия
- `script.js` — мобильное меню и демонстрационная обработка формы

## Как открыть

Откройте файл `index.html` двойным кликом или запустите проект через расширение Live Server в VS Code.

## Что заменить перед публикацией

1. Имя и описание преподавателя.
2. Телефон, почту, город и ссылки на социальные сети.
3. Фотографии.
4. Отзывы.
5. Обработчик формы. Сейчас форма только показывает уведомление в браузере.

## Бесплатная публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, `styles.css` и `script.js`.
3. Откройте `Settings → Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/root`, затем нажмите `Save`.
